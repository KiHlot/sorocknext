# Роли и общие правила

## Контекст проекта
- **Проект**: Новостной портал `sorock.ru`.
- **Задача**: Переписать фронтенд с React SPA на **Next.js (App Router, TypeScript)**.
- **Бэкенд**: пока **WordPress (REST API)**, в будущем миграция на **Laravel** (этот этап отложен).
- **Авторизация**: **будет полностью удалена позже, пока пусть болтается** — портал публичный. Все страницы, компоненты, API-эндпоинты и зависимости, связанные с авторизацией, администрированием, JWT, профилями пользователей, удалены.

## Общие правила для ассистента
1. **Генерируй код строго по указанным правилам**:
    - **Только абсолютные импорты** (`@/...`).
    - Компоненты – стрелочные функции с явным типом (`FC<Props>`).
    - Все функции и методы должны иметь явные типы аргументов и возврата.
    - Используй современный синтаксис (стрелочные функции, шаблонные строки, деструктуризацию, `async/await`).
2. **Для стилей** используй **SCSS-модули** (если не указано иное). Глобальные стили допустимы только в `src/styles/`.
3. **Обязательно учитывай содержимое** `structure.txt`, `pattern-front.md` и `pattern-back.md`:
    - Это определяет существующие файлы, избегает дублирования, соблюдает единый стиль и правильное размещение новых файлов.
4. **Если требуется дополнительная информация** – я обращусь к этим файлам или запрошу уточнения.
5. **Старайся выдавать один наиболее подходящий результат** (максимум два, если варианты принципиально отличаются).
6. **Не додумывай и не придумывай то, о чём не просят** – строго по заданию.
7. **Все данные для фронта получай через публичные эндпоинты WordPress REST API** (без JWT). Авторизация не используется.
8. **Изображения**: используй `next/image` с `remotePatterns` для доменов WordPress (локальный и продакшн).
9. **SEO**: используй `export const metadata` или `generateMetadata` в серверных компонентах.
10. **Для одиночных записей** используй `generateStaticParams` + ISR (`revalidate`) для всех 5000+ статей.
